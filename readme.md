# 📚 공부 습관 대시보드 (Study Habit Dashboard)

파이썬과 Streamlit, Pandas를 활용하여 만든 간단한 학생 공부 습관 분석 웹 애플리케이션입니다.

## ✨ 주요 기능
- **핵심 지표 요약**: 전체 학생 수, 평균 점수, 평균 공부시간을 한눈에 확인
- **맞춤형 필터**: 슬라이더를 통해 원하는 최소 공부시간 이상의 학생들만 필터링
- **데이터 시각화**: 
  - 공부시간에 따른 점수 분포 산점도(Scatter Chart)
  - 학생별 점수 비교 막대 그래프(Bar Chart)

## 🛠️ 사용 기술
- Python
- Streamlit
- Pandas
